Настройка сертификата сайта

Самоподписанный сертификат шифрует соединение, но браузер показывает предупреждение, пока сертификат не добавлен в доверенные на вашем компьютере.

{% if cert_available %}

1. Скачайте скрипт для вашей ОС (адрес сервера уже прописан внутри)

  • Windows — trust-windows.cmd
  • Linux — trust-linux.sh
  • macOS — trust-macos.sh

2. Запустите один раз от администратора

Windows (запуск от администратора — двойной щелчок или из cmd):

trust-windows.cmd

Linux:

chmod +x trust-linux.sh sudo ./trust-linux.sh

macOS:

chmod +x trust-macos.sh sudo ./trust-macos.sh

Скрипт сам скачает сертификат с сервера и установит его. После этого перезапустите браузер.

Скачать сертификат вручную (если нужен без скрипта). Для Docker+WSL на сервере: windows-forward-ports.ps1.

{% else %}

Сертификат на сервере пока не создан. Перезапустите proxy или задайте SSL_CERT_CN в .env.

{% endif %}
